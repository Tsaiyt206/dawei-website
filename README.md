# Dawei Campus Case Exhibition

Static HTML, CSS, and JavaScript site for the Dawei campus case exhibition.

## Local preview

From the repository root, run `python -m http.server 8767` and open
`http://127.0.0.1:8767/`.

## Netlify

Import this repository from GitHub. The publish directory is the repository
root, and no build command is required. `netlify.toml` records the publish
directory.

The videos in `assets/videos` are web-ready copies. The original masters are
kept outside this repository so the GitHub file limit is respected.
